# Лайт-Пак — демонстрация сайта

Готовая статическая демонстрация: 2 005 товаров, фотографии, категории, поиск и локальная корзина. Заказы и вход имитируются в браузере, данные не отправляются в магазин. Серверная часть и приём платежей отсутствуют. Индексация поисковиками отключена.

## GitHub Pages

Файлы сайта находятся в `docs/`. Пути настроены для https://nation9111x.github.io/lite-pack-demo/.

В Settings → Pages выберите Source → Deploy from a branch, ветку `main`, папку `/docs`. Обновления автоматически публикуются после отправки изменений в `main`.

Сборка уже готова: устанавливать зависимости и запускать npm не требуется. При переименовании репозитория нужно также изменить базовый путь `/lite-pack-demo/` в HTML, CSS, основном JS и manifest.

Архив содержит готовую сборку, а не исходный проект разработки. Внешние карты, документы и резервные фотографии могут требовать доступа к исходным сервисам.
