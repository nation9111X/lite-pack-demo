# Лайт-Пак

Демо: https://nation9111x.github.io/lite-pack-demo/

11 ноября 2026 года в `docs/` подготовлена новая статическая сборка из предоставленного архива. В ней 2 005 товаров. Для GitHub Pages исправлены базовые пути и восстановлены отсутствующие варианты фотографий.

## Публикация

GitHub Pages публикует ветку `main`, папку `/docs`. В `source/` сохранены исходники предыдущей сборки 2.4.0 от 1 ноября 2026 года. Обновлённый архив содержит готовый сайт без исходников. Сгенерированные фотографии хранятся в `docs/pimg/`.

Для пересборки предыдущей версии в PowerShell, из `source/`:

```powershell
npm.cmd ci
Copy-Item -LiteralPath ../docs/pimg -Destination public/pimg -Recurse
$env:VITE_BASE='/lite-pack-demo/'
npm.cmd run preview:static
```

Результат — `source/dist/`, содержимым которого обновляется `docs/`.

## Исправления производительности в исходниках 2.4.0

- Нативная прокрутка вместо непрерывного цикла Lenis; ссылки остаются доступны во время движения страницы.
- Удалены искусственные задержки 40 мс в демо-запросах и 650 мс между вопросами консультанта.
- Сжатый каталог 336 КБ предзагружается; запасной JSON — около 2,1 МБ.
- Декоративные анимации, включая псевдоэлементы, приостанавливаются вне экрана и при скрытой вкладке; удалённые элементы снимаются с наблюдения.
- Сохранены новый дизайн, тёмная тема, конвейер товаров и адаптация новой версии для телефона.

В локальной проверке главной число работающих вне экрана бесконечных CSS-анимаций снизилось с 1 до 0. Остальные RAF-эффекты проверены по исходникам: сцена коробки и конвейер останавливаются после завершения движения. Точные CPU/FPS и сетевые задержки браузерный инструмент не предоставляет; нулевая задержка при любом интернете не заявляется.
