# Дизайн-система «Лайт-Пак» — направление «Развёртка»

## Идея

Лайт-Пак производит и продаёт упаковку. Интерфейс сделан языком самой упаковки:
**крафт-картон, линии высечки (пунктир), метки приводки на углах, этикетки с перфорацией.**
Всё сдержанно: это технические детали печатной продукции, а не декор ради декора. Основа — чистый
каталог, где покупатель (кафе, магазин, частный покупатель) быстро находит товар и собирает корзину.

Три фирменных приёма:
1. **Коробка-развёртка на первом экране.** Крафтовая коробка, собранная на CSS 3D, с фирменной зелёной
   лентой. Покачивается за курсором, при прокрутке раскрывает клапаны. Без 3D-библиотек, ~0 КБ ассетов.
   При `prefers-reduced-motion` — статичная изометрия.
2. **Карточка-этикетка.** Товар — белая этикетка; цена отделена «линией отрыва» (пунктир с двумя
   полукруглыми вырезами по краям). Остатки и кратность набраны моношрифтом, как маркировка на коробе.
3. **Корзина-короб.** Иконка корзины в шапке — короб, который «наполняется» по мере приближения к
   минимальной сумме заказа (данные `deliveryPriceInfo.minOrderPrice` из API). В корзине — полоса
   «упаковочной ленты» с текстом «Не хватает N ₽ до мин. суммы заказа».

| `--brand-black` | `#000000` | «ЛАЙТ» в логотипе |
| `--brand-action` | `#19B236` | кнопки «В корзину» на старом сайте |
| `--brand-deep` | `#0D6E20` | иконки и ссылки («Войти», закрыть) |
| `--brand-banner` | `#158B2D` | зелёный баннер контактов |
| `--brand-tint` | `#E1F7E0` | светлые подложки кнопок |
| `--brand-ink` | `#00201E` | основной цвет текста |

Логотип: `public/brand/logo.png` (вырезан из 512-px иконки без масштабирования вверх), не перекрашивается,
не искажается, минимальная ширина 96 px, отступ вокруг — не меньше высоты буквы «П».

**Доступность цвета.** Белый текст на `#19B236` даёт 2.8:1 — ниже AA. Поэтому основные кнопки — на
`#00671E` (7.1:1 с белым), а `#19B236` — акцент: заливки с тёмным текстом `--ink` (6.1:1), индикаторы,
прогресс, фокус-кольца.

```
--ink-3:        #55635F   подписи, моно-метки (5.7:1 на paper, 5.2:1 на paper-2, 6.3:1 на card)

--accent-tint:  #E1F7E0
--signal:       #C2410C   скидки, ошибки (5.2:1 на card)
--warn-bg:      #FFF4D6   предупреждения («Честный ЗНАК», ограничения)
```

Фирменные эффекты (с 2.4.0) берутся только из мира упаковки и не отодвигают товары: лента с прессом на главной,
распаковка карточек, чертёж развёртки за коробкой. Облака частиц и сцены на WebGL не использовать: они заняты на сайте-резюме владельца.

Тёмная тема (с 2.3.0) задана блоком `:root[data-theme='dark']` в `tokens.css`: цвета в компонентах только через токены.
Фото товаров лежат на светлых плашках `--plate` и в тёмной теме: товар должен выглядеть как есть.

## Типографика

- **Заголовки:** Geologica (variable, кириллица), 700–800, плотный трекинг `-0.02em`.
  Геометричный гротеск с острыми срезами — перекликается с жирным «ЛАЙТ» в логотипе и высечкой.
- **Текст и интерфейс:** Onest (variable, кириллица), 400/500/600. Создан для экранов, отличная кириллица.
- **Маркировка (остатки, кратность, артикулы):** системный моноширинный `ui-monospace, "Cascadia Mono", "Roboto Mono"`.
- Шрифты самохостятся (`@fontsource-variable/*`), подгружаются только нужные `unicode-range` (кириллица+латиница).

Шкала (clamp, мобильный → десктоп):
```
--fs-hero:  clamp(2.25rem, 1.4rem + 4.2vw, 4.75rem)   H1 первого экрана
--fs-h1:    clamp(1.75rem, 1.3rem + 2vw, 3rem)
--fs-h2:    clamp(1.375rem, 1.15rem + 1vw, 2rem)
--fs-h3:    1.125rem
--fs-body:  1rem (16px), line-height 1.5
--fs-small: 0.875rem
--fs-mono:  0.8125rem, letter-spacing 0.02em, uppercase для меток
```

## Сетка и отступы

- Контейнер `max-width: 1360px`, поля 16 px (мобильный) / 24 px (≥768) / 32 px (≥1280).
- Шаг отступов 4 px: `--s1:4 --s2:8 --s3:12 --s4:16 --s5:24 --s6:32 --s7:48 --s8:64 --s9:96`.
- Сетка товаров: `repeat(auto-fill, minmax(168px, 1fr))` на мобильном (2 колонки на 375), до 5 колонок на 1440.
- Тач-цели ≥ 44×44 px.

## Движение

- Характер: «физично и коротко». Длительности 140 / 220 / 360 мс, кривая `cubic-bezier(.2,.8,.2,1)`,
  для пружинящих элементов `cubic-bezier(.34,1.56,.64,1)`.
- Ховер карточки: подъём на 4 px + тень `--shadow-2`; пунктир высечки становится зелёным.
- «В корзину»: крафтовый мини-короб улетает из кнопки в иконку корзины (Web Animations API), короб в шапке
  подпрыгивает и подрастает уровень заполнения.
- Переходы между страницами: View Transitions API (кросс-фейд + сдвиг 8 px), где не поддерживается — без анимации.
- Появление секций при прокрутке: сдвиг 12 px + прозрачность. Контент **не скрыт** без JS: класс
  `.reveal` включается только скриптом.
- `prefers-reduced-motion: reduce` — отключаются все анимации движения, остаются мгновенные смены состояний;
  коробка на первом экране статична.

### Версия 2.1 — «живой» интерфейс
- Плавная прокрутка (Lenis) — только мышь/тачпад на ПК; в окнах, меню и списках — родная прокрутка.
  Тонкая полосатая «лента прогресса» сверху показывает, сколько страницы прочитано.
- Кнопки: на ховере подъём 2 px + увеличение 3,5 %, смена заливки на заметно более светлую/контрастную
  (`--btn-bg-h`, `--btn-fg-h`, `--btn-bd-h` на каждый вариант), блик по поверхности, стрелка сдвигается;
  при нажатии — сжатие 0,96 и «волна» от точки касания (на телефоне тоже).
- Главные кнопки (Каталог, Корзина, CTA первого экрана) — «магнитные»: слегка тянутся к курсору.
- Карточки, плитки и фото товара наклоняются за курсором (до 7°) с бликом — лёгкий 3D без библиотек.
- Сегменты «Доставка / Самовывоз» и т. п. — скользящая подложка под активным пунктом.
- «В корзину»: иконка «+» делает оборот, вылетают крафтовые и зелёные «конфетти», короб летит в корзину,
  кнопка превращается в счётчик с отметкой «✓ Добавлено»; цифры счётчика прокручиваются вверх/вниз.
- Выпадающие списки — свои (в стиле сайта), с клавиатурой и экранным диктором (WAI-ARIA listbox).
- Лента в подвале — бесшовный цикл (две одинаковые половины, сдвиг ровно на 50 %).
- Калькулятор партии и 3D-просмотр габаритов на странице товара — см. `CHANGELOG.md`, версия 2.1.
