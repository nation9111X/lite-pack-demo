# Лайт-Пак — новый фронтенд lite-pack.ru

Новая витрина интернет-магазина «Лайт-Пак» вместо Flutter Web. Работает на том же API (`/api/v1/*`),
сохраняет все маршруты, тексты, логику корзины, адресов, входа по SMS, оформления, заказов и Метрику.

Стек: Vite 5 + React-совместимый Preact 10 + TypeScript, React Router 6, собственные стили (CSS-токены),
пререндер HTML при сборке. Подробности: `docs/SITE_AUDIT.md` (аудит и API-контракт), `docs/DESIGN.md` (дизайн-система),
`docs/OPEN_QUESTIONS.md` (что уточнить), `CHANGELOG.md`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, API и картинки проксируются на https://lite-pack.ru
```

Другой бэкенд (например, стенд): `LITEPACK_API=https://website-stage.service.lite-pack.ru npm run dev`.

Карта в окне адреса — Яндекс Карты 2.1. Ключ JS API задаётся в `.env.local` (в git не попадает):
`VITE_YMAPS_KEY=…` — тот же ключ, что у старого приложения на lite-pack.ru. Без ключа карта тоже работает.

`npm run dev:demo` — разработка без сервера магазина (демо-режим: каталог из снимка, корзина и адреса в браузере).

## Сборка

```bash
npm run snapshot     # обновить снимок каталога data/snapshot.json (≈10 мин, нужен перед свежим пререндером)
npm run sitemap      # обновить public/sitemap.xml по живому API (или npm run sitemap:snapshot — из снимка)
npm run images       # улучшенные фото товаров → public/pimg/ (нужен `cd tools && npm install`; первый раз ≈12 мин,
                     # дальше — только новые фото). Без этого шага сайт берёт картинки из сервиса ресайза, как раньше.
npm run build        # проверка типов → клиентская сборка → SSR-бандл → пререндер ~2200 страниц в dist/
npm run preview      # локальный просмотр dist с прокси на API
```

`npm run build:spa` — сборка без пререндера (если нужно срочно, без снимка каталога).

## Деплой

1. `npm run build` → папка `dist/` (~66 МБ: статические HTML главной, всех категорий и товаров + ассеты; плюс ~330 МБ улучшенных фото в `dist/pimg/`).
2. Скопировать содержимое `dist/` в веб-корень nginx. **Не удалять** серверные пути `/static/legal/*.pdf`
   (правовые документы) и всё, что обслуживает `/api/` и ресайз картинок. Старую сборку Flutter сохранить
   отдельно для отката.
3. Добавить в конфиг nginx блок из `docs/nginx.conf` (кэш ассетов, фолбэк `try_files $uri $uri/index.html /app.html`).
   Там же — две настройки сервера, которые дают основной прирост скорости: gzip для `/api/` и кэш ресайза картинок.
4. Папка `dist/pimg/` (улучшенные фото) копируется вместе со всем `dist/`; в nginx для неё — блок `location /pimg/`
   из `docs/nginx.conf`. В git эти файлы не хранятся: их пересобирает `npm run images`.
5. Цены и остатки в пререндере скрыты и всегда берутся из живого API; пересобирать сайт нужно только чтобы
   новые товары и категории получили статические страницы (рекомендуется ночная пересборка: `snapshot` + `images` + `build`).

Открытые вкладки старого сайта увидят новую версию сами: изменён `version.json`, старое приложение предложит перезагрузку.

## Показ заказчику

**Демо без сервера:** https://nation9111x.github.io/lite-pack-demo/ (GitHub Pages, сайт лежит в подпапке).
Каталог, цены и остатки зафиксированы из `data/snapshot.json` на дату снимка (она указана в полосе над шапкой);
корзина, адреса, вход (любой код) и «заказы» работают только в браузере и никуда не отправляются (`src/api/demo.ts`).

```bash
VITE_BASE=/lite-pack-demo/ npm run preview:static   # в Git Bash на Windows впереди ещё MSYS_NO_PATHCONV=1
```

Затем содержимое `dist/` загружается в корень репозитория `lite-pack-demo`. Для сайта в корне домена `VITE_BASE` не нужен.
После показа соберите обычную версию: `npm run build`.

**Живой предпросмотр с настоящим каталогом и заказами:** `npm run preview:netlify` → https://lite-pack-redesign.netlify.app
(API пересылается на lite-pack.ru). Netlify, Vercel и Cloudflare Pages из России открываются только через VPN,
поэтому для показа в России — демо выше.

## Проверки

Инструменты проверки лежат отдельно в `tools/` (свой `package.json`, в сборку сайта не попадают):

```bash
cd tools && npm install && npx playwright install chromium
node e2e.mjs http://localhost:5173 375        # сценарий покупателя на боевом API (без SMS и без заказов)
node mock-api.mjs                              # мок закрытых разделов (порт 5199), затем в корне:
#   LITEPACK_API=http://localhost:5199 npx vite --port 5192
node e2e-auth.mjs http://localhost:5192 1440   # вход, оформление, оплата, заказы, профиль — на мок-API
node lh.mjs http://localhost:4173 prod         # Lighthouse (мобильный) по главной, категории, товару
node axe.mjs http://localhost:4173             # axe-core, WCAG 2.2 AA
node serve-dist.mjs 5196 [--gzip-api] [--cache-images]   # dist как на nginx (с рекомендуемыми настройками)
node map-check.mjs http://localhost:5173       # карта адреса: перетаскивание, «где я», поиск, самовывоз
node cart-check.mjs http://localhost:5193      # корзина в демо: адрес по карте, крышки, «Вернуть», панель
node podbor-check.mjs http://localhost:5193 --all   # консультант: все сценарии и приоритеты, печатает комплекты
node pairs.mjs                                 # какие крышки к каким основаниям подбираются
node phone-check.mjs http://localhost:5193     # телефон: обе темы, сцена, ширина, снимки в docs/review
node alive-check.mjs http://localhost:5193     # плавность при замедлении ×4, поворот коробки пальцем, переходы, тема
node region-check.mjs http://localhost:5193    # смена региона, «Вернуть адрес», редкие экраны в тёмной теме
node axe2.mjs http://localhost:5193            # axe в обеих темах на телефоне и компьютере
node idle-check.mjs http://localhost:5193      # загрузка главного потока в покое и при прокрутке
node chunk-check.mjs http://localhost:5193     # обрыв связи: файл страницы или карты не загрузился
node unbox-check.mjs http://localhost:5193     # распаковка карточек: не залипает, лимит соблюдается
```

## Структура

```
src/api        клиент API (заголовки, анонимный токен, ранний старт), типы, эндпоинты
src/store      сессия и адреса, корзина (кратность, оптимистичные изменения), UI-состояние, сценарии
src/components шапка, мега-меню, поиск, карточка-этикетка, корзина, адреса, вход, 3D-коробка, диалоги
src/pages      главная, категория, товар, поиск, корзина, оформление, заказы, профиль, справка, контакты
src/lib        кэш запросов, форматирование, Метрика, SEO, картинки, анимации, тема, живые эффекты и распаковка карточек (alive)
scripts/       пререндер, sitemap, картинки первого экрана
tools/         разведка, снимок каталога, e2e, Lighthouse, axe, мок-API (не часть сайта)
data/          снимок каталога и тексты старого приложения
docs/          аудит, дизайн, вопросы, nginx, Lighthouse-отчёты, скриншоты «было/стало»
```
